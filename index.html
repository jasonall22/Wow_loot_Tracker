MANUAL RAID BACKUP

Import a Loot Tracker raid

On the backup looter's computer, select the raid in Loot Tracker, click Export, then type /reload. Choose that account's WTF/Account/<account>/SavedVariables/APOCLootTrackerBeta.lua file here. Only the selected raid is sent to the website. Importing a permanently deleted raid deliberately adds it back.
